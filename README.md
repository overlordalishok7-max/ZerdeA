# ZerdeAI
Авторы: Группа АЖ-401 Бақыт Мұхаммедәлі Қайрат Нұрғиса Нұрымбай Алишер.

Учебное приложение для преподавателей и студентов: задания, попытки, оценки, материалы и общение в группах. Интерфейс работает на русском и казахском языках.

> Это восстановленный и доработанный проект. Исходный Java-код был частично восстановлен из установочного пакета; оригинальный JAR сохранён в `baseline/` для сравнения.

## Скачать и запустить

Откройте раздел [Releases](../../releases/latest) и скачайте:

- `ZerdeAI_Project.zip` — полный проект с исходниками, ресурсами, зависимостями и инструкциями;
- `ZerdeAI_Setup.exe` — Windows-установщик.

Распакуйте архив целиком. Для запуска на Windows используйте `START_WINDOWS.bat`. Для сборки и проверок нужны команды `BUILD_PROJECT.cmd` и `TEST_PROJECT.cmd`; сборка исходников требует полного JDK 17.

## Возможности.

- Аккаунты преподавателей и студентов, группы и назначения.
- Создание заданий, сохранение попыток, оценивание и история изменений.
- Библиотека материалов, резервные копии и экспорт результатов.
- Чаты студента с преподавателем группы, курсы и ИИ-тьютор.
- Аватары собеседников в чате, поиск диалогов и история ИИ-тьютора по вопросам.
- Светлая и тёмная темы, русский и казахский интерфейс.
- Локальная база H2 без обязательного доступа к интернету.

## Как проект развивался.

Этапы восстановления и разработки описаны в [PORTFOLIO_RU.md](PORTFOLIO_RU.md): от анализа установщика и восстановления исходников до серверной проверки прав, интерфейса, тестов и упаковки Windows-сборки.

## Технологии

Java 17, JavaFX/WebView, встроенный HTTP-сервер, H2, HTML, CSS и JavaScript. Схема запуска, сборки и проверки приведена в [README_RU.md](README_RU.md) и [PROJECT_MAP_RU.md](PROJECT_MAP_RU.md).

## Статус и ограничения

- H2 — локальный режим. Supabase в приложение пока не подключён.
- Для обмена данными между несколькими пользователями нужен один компьютер-сервер в сети.
- Автоматические проверки: 111 проверок и 3 сценария запуска пройдены; тесты используют временные базы и имитированные внешние сервисы.
- Setup EXE собран, но полные сценарии установки, обновления и удаления через Windows отдельно не проверялись.

Данные приложения хранятся отдельно от файлов программы. Не публикуйте собственную базу, резервные копии или ключи API.
